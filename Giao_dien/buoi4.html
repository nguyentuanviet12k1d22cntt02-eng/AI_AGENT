Module 01 — Thiết Lập Đám Mây

Kích Hoạt Cặp Đôi API Sức Mạnh: Google Sheets API & Google Drive API

Để AI Agent có thể giao tiếp với hệ sinh thái tài liệu của Google, bước tiên quyết là đăng ký dịch vụ trên Google Cloud Console.

Google Sheets API

Dịch vụ đọc & ghi bảng tính doanh nghiệp

API này cấp phép cho mã nguồn lập trình có thể:

  • Đọc toàn bộ ma trận dữ liệu hàng nghìn dòng trong vài mili-giây.
  • Ghi chèn dữ liệu, cập nhật ô tính và thiết lập công thức tính toán.
  • Tạo định dạng có điều kiện (Conditional Formatting), tô màu cảnh báo tồn kho.
  • Render biểu đồ trực quan (Charts): Vẽ các biểu đồ 3D dạng thanh, cột và tròn tự động.
Thao tác trong video: Tìm kiếm Google Sheets API ➔ Bấm Enable.

Google Drive API

Dịch vụ quản trị tệp tin & thư mục đám mây

API này giữ vai trò "người gác cổng" hạ tầng lưu trữ:

  • Định vị chính xác vị trí tệp Google Sheet dựa theo tên tệp hoặc thư mục.
  • Phân quyền chia sẻ (Permissions API), kiểm tra quyền đọc/ghi của tài khoản dịch vụ.
  • Tự động tạo thư mục sao lưu và di chuyển tệp báo cáo vào đúng vị trí của phòng ban.
  • Hỗ trợ đồng bộ hóa tệp với ứng dụng Google Drive Desktop.
Thao tác trong video: Tìm kiếm Google Drive API ➔ Bấm Enable.

Module 02 — Danh Tính Số Cho AI

Khởi Tạo Service Account & Tải Tệp Khóa Bảo Mật credential.json

AI Agent không thể đăng nhập bằng tài khoản Gmail cá nhân kèm mã OTP. Chúng ta cần cấp cho Agent một Tài khoản dịch vụ (Service Account) độc lập hoạt động 24/7.

4 Thao Tác Cốt Lõi Trên IAM & Admin

1
Mở menu điều hướng ➔ Chọn IAM and Admin ➔ Chuyển đến mục Service Accounts.
2
Nhấn nút Create Service Account. Nhập tên tài khoản là Tuanviet. Hệ thống sẽ tự tạo email định danh dạng:
tuanviet@hello-511807.iam.gserviceaccount.com
3
Bấm vào tài khoản vừa tạo ➔ Chuyển sang tab Keys ➔ Chọn Add Key ➔ Bấm Create new key.
4
Chọn định dạng JSON rồi bấm Create. Tệp khóa bí mật sẽ tự động tải về máy tính của bạn.

Cấu Trúc Khóa Bí Mật credential.json

BẢO MẬT TUYỆT ĐỐI 
{
  "type": "service_account",
  "project_id": "hello-511807",
  "private_key_id": "9a7f4c2b810d...",
  "private_key": "-----BEGIN RSA PRIVATE KEY-----\nMIIEpAIBAAKCAQEA0...",
  "client_email": "tuanviet@hello-511807.iam.gserviceaccount.com",
  "client_id": "108392817291827364512",
  "auth_uri": "https://accounts.google.com/o/oauth2/auth",
  "token_uri": "https://oauth2.googleapis.com/token"
}
LƯU Ý SỐNG CÒN: Tệp credential.json chứa private key có thể toàn quyền can thiệp vào đám mây của bạn. Tuyệt đối KHÔNG commit file này lên GitHub công khai. Phải thêm vào .gitignore!
Chuẩn Hóa Không Gian Làm Việc Tại Desktop/hello (02:36 - 03:59)

1. Tạo thư mục mang tên hello trên màn hình Desktop.
2. Copy tệp khóa JSON vừa tải về từ thư mục Downloads vào Desktop/hello và đổi tên thành credential.json.
3. Mở Notepad, dán email Service Account vừa copy vào và lưu thành tệp ten mail.txt để lưu vết.

Module 04 — Bắt Tay Bảo Mật

Giải Mã Cái Bắt Tay Bảo Mật (Security Handshake) Cấp Quyền Bảng Tính

Tại sao đã có file credential.json mà AI Agent vẫn có thể bị chặn truy cập? Hiểu đúng nguyên lý phân quyền trên Google Sheets để không bao giờ gặp lỗi 403 Forbidden.

Nguyên Lý "Cái Bắt Tay Bảo Mật"

Một file Google Sheet do bạn tạo ra thuộc về quyền sở hữu cá nhân của bạn. Service Account dù có API Key nhưng vẫn là một thực thể người dùng bên ngoài:

Nguyên nhân lỗi 403 PERMISSION_DENIED: Nếu bạn chưa chia sẻ file Sheet cho Service Account, Google Cloud sẽ từ chối mọi yêu cầu đọc/ghi để bảo vệ dữ liệu người dùng.

Giải pháp (07:50 - 08:13): Mở bảng tính Google Sheet mang tên báo cáo ➔ Bấm nút Chia sẻ (Share) ở góc phải ➔ Dán email của Service Account và chọn vai trò Người chỉnh sửa (Editor).

Cách Trích Xuất Spreadsheet ID Cho AI

Mỗi tệp Google Sheet sở hữu một định danh duy nhất (Spreadsheet ID) nằm ngay trên thanh địa chỉ URL:

https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms/edit

Phần bôi xanh chính là SPREADSHEET_ID. Bạn chỉ cần đưa đoạn mã này vào câu prompt hoặc file cấu hình, AI Agent sẽ tự động kết nối chính xác vào bảng tính mục tiêu.

Mẹo: Bạn cũng có thể thiết lập quyền "Bất kỳ ai có đường liên kết đều có thể chỉnh sửa" nếu làm việc trong môi trường thử nghiệm nội bộ.

Case Study Kỹ Thuật

Vòng Lặp Tự Sửa Lỗi (Self-Debugging Loop) Của AI Agent Khi Gặp Lỗi 3D Chart

Điểm vượt trội của AI Agent so với script code thông thường là khả năng tự phản biện (Reflection), đọc thông báo lỗi từ Google API và tự động sửa mã nguồn mà không cần con người can thiệp.

Bước 1: Bắt Lỗi API

Phát Hiện Ngoại Lệ

AI Agent gửi yêu cầu tạo Column chart với thuộc tính is3D: true. Google Cloud trả về mã lỗi 400:

googleapiclient.errors.HttpError: 400 Invalid argument: 3D is not supported for ColumnChart.
Bước 2: Suy Luận

Phân Tích Nguyên Nhân

AI Agent lập tức tra cứu đặc tả kỹ thuật Google Sheets API và nhận diện quy chuẩn:

Specification Rule: Chỉ có biểu đồ BarChart (thanh ngang) và PieChart (tròn) mới hỗ trợ cờ 'is3D'.
Bước 3: Sửa Mã Nguồn

Chuyển Đổi Sang 3D Hợp Lệ

AI Agent viết lại hàm tạo biểu đồ, thay thế COLUMN bằng BAR 3D và bổ sung PIE 3D:

chart_spec = {
  'barChart': {'is3D': True},
  'pieChart': {'is3D': True}
}
Bước 4: Thành Phẩm

Render Thành Công 100%

AI Agent chạy lại script. Bảng tính lập tức hiển thị 2 biểu đồ 3D lộng lẫy cùng các thẻ KPI chỉ số kho hàng:

SUCCESS: 2 Charts created.
1. Biểu đồ thanh 3D Xuất-Nhập
2. Biểu đồ tròn 3D Tỷ trọng ngành
Bài Học Tư Duy: Đừng Sợ Lỗi — Hãy Để AI Agent Tự Tối Ưu

Khi giao việc cho AI Agent làm việc với API của bên thứ ba (Google, Facebook, Shopee), việc xảy ra xung đột tham số là điều bình thường. Thay vì hoảng loạn, người dùng chỉ cần ra lệnh: "Hãy đọc kỹ thông báo lỗi từ API, tra cứu lại tài liệu chính thức và tự sửa lại mã nguồn cho tôi". Agent sẽ tự giải quyết 99% vấn đề kỹ thuật!
